# Handwriting fonts for synthetic text

Used by `hdr/data/synth_text.py` to render synthetic flowchart text lines for
TrOCR training (paper section III-D). They are bundled because downloading them
from GitHub on Kaggle sometimes returns an error page instead of the font file.

Source: https://github.com/google/fonts (downloaded 2026-11-14).
